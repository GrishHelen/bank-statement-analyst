# Разработка

## Код

- Держим функции небольшими, используем обычные циклы и явные условия.
  За основу берём примеры из занятий.
- Указываем типы параметров и результата у всех функций и методов.
  Для функций без результата — `-> None`.
- `cli.py` отвечает за терминал, `chat.py` — за диалог, `providers/` — за API моделей.
- Новые модули добавляем вместе с реализацией: чтение выписок — в `importers/`,
  расчёты — в `analysis/`, функции для вызова моделью (инструменты) — в `tools/` внутри `src/`.

## Зависимости и конфигурация

- Зависимости храним в одном `requirements.txt`
  с проверенными версиями.
- Неиспользуемые зависимости удаляем.
- Новые настройки добавляем в `.env.example` и описываем в README.
  При изменении значений шаблона обновляем таблицу параметров.
- Зависимости, запуск и тесты должны воспроизводиться по README.

## Данные и проверки

- Используем синтетические выписки. Реальные данные в проект не включаем.
- Ключи храним локально в `.env`, не записываем в логи и не добавляем в Git.
- Проверка HTTPS-сертификатов остаётся включённой.
- Автоматические тесты работают с подменой API-клиента. Проверки реального API
  запускаем отдельно.
- Перед сдачей изменений запускаем затронутые тесты.
  Команда запуска и настройка окружения — в [README](README.md).
